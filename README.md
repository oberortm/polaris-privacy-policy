# polaris-privacy-policy

Statische Startseite und Datenschutzerklärung für **PolarisOS**, ein privates, selbst gehostetes Werkzeug. Wird für den Google-OAuth-Zustimmungsbildschirm benötigt (Branding im Projekt `polarisos-510220`).

- Startseite: https://oberortm.github.io/polaris-privacy-policy/
- Datenschutz: https://oberortm.github.io/polaris-privacy-policy/datenschutz.html

Diese Seiten enthalten keinen Login, keine Skripte und keinen Link zur eigentlichen Anwendung.

Wichtig: Repo-Name und Dateinamen nicht ändern, ohne die beiden Links im Google-Branding mitzuändern.
